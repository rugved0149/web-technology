# ClinicEase

A responsive ReactJS clinic appointment booking demo built with Vite.

## Features
- Patient appointment form with client-side validation and field-specific error messages
- Doctor selection, date/time validation, duplicate doctor-slot prevention
- Appointment search, status filtering, cancellation, dashboard statistics
- React components/state/event handling and localStorage persistence
- Responsive desktop and mobile layout

## Run locally
```bash
npm install
npm run dev
```

## Build for deployment
```bash
npm run build
npm run preview
```

Demo note: appointments are stored in this browser only. This is an academic frontend demo, not a real healthcare booking service.
